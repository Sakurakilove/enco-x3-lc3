# Enco X3 LC3

为 **OPPO Enco X3** 补充 LE Audio / LC3 连接、回连和双耳控制恢复的 LSPosed 模块。安装后可在应用内配置耳机，无需修改 APK。

**[下载 v0.20 公开预览版](https://github.com/Sakurakilove/enco-x3-lc3/releases/tag/v0.20-public-preview)** · [更新记录](CHANGELOG.md) · [问题反馈](https://github.com/Sakurakilove/enco-x3-lc3/issues)

> 当前适配依据：一加 11（PHB110）· ColorOS 16.0.5 / Android 16 · Enco X3。其他机型、ROM 和耳机尚未验证。v0.20 的修复已通过主机回归，仍待实机验证，因此继续以 **Pre-release** 发布。

## 使用前确认

- 手机已 Root，LSPosed 可正常工作。
- Enco X3 已在系统蓝牙设置中正常配对。
- ROM 已具备 LE Audio、CSIP 分组和 VCP 音量控制服务。模块依赖所检查 ColorOS 的内部接口，无法补齐缺失的驱动或协议栈。
- 测试手机此前已开启系统 LE Audio 相关属性并设置设备准入配置。模块不会自动修改这些属性或白名单；其他手机的初始配置能否直接使用尚未验证。

## 安装与使用

1. 在 [Releases](https://github.com/Sakurakilove/enco-x3-lc3/releases/tag/v0.20-public-preview) 下载 APK，并阅读该版本的安装与签名说明。
2. 在 LSPosed 启用 **Enco X3 LC3**，作用域勾选 **蓝牙 / `com.android.bluetooth`**。
3. 确认耳机已正常配对，将双耳取出充电盒。
4. 打开模块应用，点击 **「一键配置并恢复 LC3」**，首次使用授予 Root 权限。
5. 等待流程结束，再播放音乐确认双耳声音和音量控制。

操作会重启蓝牙进程，所有已连接的蓝牙设备会短暂断开；随后识别主耳地址、请求 LC3 并检查双耳控制服务。流程最长约 90 秒，期间无需重复点击。

只有同组双耳的 LE Audio、CSIP、VCP 均已连接，且可用原生控制恢复完成，才显示就绪。就绪表示服务状态通过检查，实际出声仍需播放确认；超时不会取消配对，也不会重置音量或左右平衡。

地址保存在蓝牙服务的私有目录，正常使用只需首次配置。升级后点击一次主按钮，让蓝牙进程加载新版模块，无需重启整部手机。

## 日常操作

| 你想做什么 | 操作 |
| --- | --- |
| 开启或恢复 LC3 | 点击模块的「一键配置并恢复 LC3」，或明确开启系统 LE 开关 |
| 切回普通蓝牙 | 在系统蓝牙页面关闭 LE；LDAC/SBC 由系统与耳机协商 |
| 手动断开后重新连接 | 在系统蓝牙页面重新连接已配置的耳机；v0.20 修复此流程被旧断开标记拦截的问题 |
| 导出运行记录 | 点击「导出日志」，文件保存到 `Download/enco-lc3-v0.20-日期-时间.txt` |

关闭 LE 后，模块会保存普通蓝牙选择并暂停自动恢复。系统 LC3 入口暂时不显示时，可通过模块主按钮重新请求。命令行恢复普通蓝牙、单独修复控制服务等操作见[命令行与诊断](docs/advanced.md)。

## 常见问题

**无法自动识别耳机？**

先在系统蓝牙中正常连接一次，再重试。多副 X3、改过名字或服务缓存不足时，应用会展开地址输入框；填写系统蓝牙设备详情中的**主地址**，不要填随机扫描地址或另一耳的独立 LE 地址。已有目标仍配对时会优先沿用；换另一副前先断开旧耳机。

**有声音，但双耳检查未通过或音量异常？**

保持双耳盒外，查看日志中的每耳 LE、CSIP、VCP 状态。单耳连接不会报告双耳成功。导出日志，并在反馈中附上手机型号、系统版本、耳机固件、模块版本和复现步骤。

**日志会丢失或上传吗？**

流程结束后停止读取日志，完整记录保存在应用私有目录，再次打开仍可查看。导出支持运行中快照，不受界面显示长度限制。开始新流程会覆盖应用内上次记录，已导出的文件保留。日志不会自动上传；公开分享前请隐藏无关设备地址和名称。Android 8.1/9 导出时需要保存权限。

**欢律、降噪和固件升级能用吗？**

模块只作用于蓝牙服务，厂商应用沿用原有控制通道。已有使用反馈，但降噪、手势、均衡器、多设备等功能尚未逐项验证，固件升级也未实测；原生控制就绪不代表所有厂商功能都已验证。

**支持 Enco X4 吗？**

尚未适配或验证。Release 中的 `collect-enco-x4.sh` 仅用于只读采集适配资料，[使用说明在这里](docs/advanced.md#enco-x4-适配资料采集)。

## 本版更新与验证

v0.20 修复手动断开后重新连接被拦截、快速断开重连使旧延时任务复活，以及无关厂商命令被误认为 LE 广播成功的问题。详见[更新记录](CHANGELOG.md)。

历史实机结果：v0.14 已确认双耳 LC3、音量和部分回盒回连场景；v0.18 已确认一次重配对后的双耳 LE/CSIP/VCP 同组就绪与日志导出。**v0.19 / v0.20 的模式切换与回连修复仍待实机验证。** 长时间播放、通话后的音乐恢复、手机重启和长时间回盒仍需补充测试。
